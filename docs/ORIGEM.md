# Origem dos recursos

Os modelos editáveis da pistola, M4, machete, componentes e suprimentos, os rigs dos três infectados e as poses foram gerados neste projeto com a API Python do Blender. As texturas pixeladas e os oito efeitos sonoros foram produzidos por scripts do projeto. Os sons são sínteses originais exportadas em Ogg Vorbis. Os ovos de invocação referenciam modelos que o próprio Minecraft fornece em tempo de execução.

O projeto foi preparado a partir do MDK oficial do Forge 26.3-66.1.0. Os arquivos em `src/main/resources` são os recursos usados pelo jogo. O arquivo `art/runtime.zip` preserva a cópia desses recursos usada pela compilação do GitHub. Os editáveis estão em `art/blender`. Os testes ficam em `qa` e não fazem parte do JAR do mod.
