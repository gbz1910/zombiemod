# Zombie Mod

Primeira versão em desenvolvimento para **Minecraft 26.3 / Forge 66.1.0 / Java 25**.

## Estado

Preparação do ambiente de compilação. Ainda não há versão jogável publicada.

## Escopo

Pistola semiautomática (12 munições de 9 mm), M4 automática (30 munições de 5,56 mm), zumbi comum, corredor e tanque, bandagem e kit de primeiros socorros. Modelos e animações próprios criados no Blender, com recursos exportados compatíveis com o jogo.

## Critério de entrega

O artefato final deve ser um JAR compilado e testado no jogo. Uma compilação bem-sucedida isoladamente não comprova funcionamento de armas, entidades, animações ou multiplayer. Os resultados de testes serão registrados separadamente.

A primeira execução de CI serve apenas para validar a ferramenta oficial Forge MDK, antes de integrar o conteúdo do mod.
